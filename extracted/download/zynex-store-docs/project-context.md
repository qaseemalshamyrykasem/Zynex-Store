## 1. فكرة المشروع

### الوصف

**Zynex Store** هو متجر إلكتروني متخصص في بيع الخدمات الرقمية، مصمم خصيصاً للسوق العربي واليمني. المنصة تتيح للمستخدمين شراء اشتراكات التطبيقات، أدوات الذكاء الاصطناعي، خدمات توثيق الحسابات، خدمات تليجرام، خدمات السوشيال ميديا، وغيرها من الخدمات الرقمية.

### المشكلة التي يحلها

في السوق العربي وخاصة اليمني، يواجه المستخدمون عدة تحديات عند محاولة الحصول على الخدمات الرقمية:

1. **صعوبة الدفع**: معظم المنصات العالمية لا تدعم طرق الدفع المحلية اليمنية (جيب، جوالي، فلوسك، ون كاش، محفظتي)
2. **حاجز اللغة**: معظم المنصات باللغة الإنجليزية فقط، مما يصعب الاستخدام
3. **ارتفاع الأسعار**: الوسطاء يرفعون الأسعار بشكل كبير
4. **انعدام الثقة**: صعوبة التحقق من موثوقية البائعين
5. **بطء التسليم**: عمليات التسليم قد تستغرق أياماً بدلاً من ساعات

### الحل

Zynex Store يقدم حلاً متكاملاً:

- ✅ دعم كامل لجميع المحافظ اليمنية المحلية
- ✅ واجهة عربية كاملة (RTL) مع دعم ثنائي اللغة
- ✅ أسعار تنافسية مباشرة بدون وسطاء
- ✅ نظام تقييمات ومراجعات لبناء الثقة
- ✅ تسليم فوري أو خلال ساعات قليلة
- ✅ ضمان كامل واسترداد في حال عدم الرضا

### الفئة المستهدفة

| الفئة | الوصف |
|---|---|
| **المستخدمون اليمنيون** | الشباب والمحترفون الذين يحتاجون خدمات رقمية ويواجهون صعوبة في الدفع الدولي |
| **المغتربون العرب** | اليمنيون والعراقيون والسوريون في الخارج الذين يريدون إرسال خدمات لأهليهم |
| **أصحاب الأعمال** | رواد الأعمال الذين يحتاجون أدوات رقمية لأعمالهم |
| **المطورون** | المبرمجون الذين يحتاجون اشتراكات أدوات التطوير والذكاء الاصطناعي |
| **صناع المحتوى** | المؤثرون الذين يحتاجون خدمات السوشيال ميديا وتوثيق الحسابات |

## 2. أهداف المشروع

### الأهداف الرئيسية

#### 🎯 الهدف الأول: تقديم منصة عربية احترافية للخدمات الرقمية
بناء منصة تجارة إلكترونية متكاملة باللغة العربية تتيح شراء وبيع الخدمات الرقمية بسهولة وأمان، مع التركيز على تجربة المستخدم العربية.

#### 💰 الهدف الثاني: تمكين الدفع المحلي
توفير حلول دفع محلية تناسب المستخدم العربي واليمني، بما في ذلك جميع المحافظ الرقمية اليمنية والطرق الدولية.

#### ⚡ الهدف الثالث: تسليم سريع وموثوق
ضمان تسليم الخدمات الرقمية في أسرع وقت ممكن (فوري إلى 24 ساعة) مع تتبع حالة الطلب وضمان الاسترداد.

#### 🤖 الهدف الرابع: ذكاء اصطناعي متكامل
استخدام تقنيات الذكاء الاصطناعي لتحسين تجربة المستخدم من خلال التوصيات الذكية والبحث المتقدم ودعم العملاء.

## 3. فلسفة التصميم

### المبادئ الأساسية

Zynex Store يتبع فلسفة تصميم **"Futuristic Minimal Luxury Modern SaaS"** — وهي مزيج من المستقبلية والبساطة والفخامة والحداثة:

#### 🌌 Futuristic (مستقبلي)

- **تأثيرات Glass-morphism**: الخلفيات الشفافة مع ضبابية زجاجية تعطي شعوراً بالتكنولوجيا المتقدمة
- **كرات Gradient متحركة**: عناصر خلفية متحركة تعطي حيوية وعمقاً
- **تأثيرات Shimmer**: وميض خفيف عند التحويم يعطي إحساساً بالتفاعلية
- **خطوط شبكية**: أنماط شبكية دقيقة تعزز الإحساس التقني

#### ✨ Minimal (بسيط)

- **مساحات بيضاء سخية**: تباعد كافي بين العناصر يسهل القراءة
- **ألوان محدودة**: لوحة ألوان مبنية على 4 ألوان رئيسية (بنفسجي، سماوي، أخضر، كهرماني)
- **طبقات معلومة واضحة**: كل عنصر في مكانه المناسب بلا فوضى
- **أيقونات بسيطة**: استخدام أيقونات Lucide البسيطة والمتسقة

#### 💎 Luxury (فاخر)

- **تدرجات لونية غنية**: Gradient رئيسي (بنفسجي → سماوي) يعطي شعوراً بالفخامة
- **ظلال دقيقة**: ظلال خفيفة مع لون بنفسجي (shadow-purple-500/5) تعطي عمقاً
- **تأثيرات التحويم**: تفاعلات سلسة ومتقنة عند التحويم (scale, glow, shimmer)
- **خطوط عريضة**: عناوين بخطوط عريضة تعطي قوة بصرية

#### 🚀 Modern SaaS Style (نمط SaaS حديث)

- **بطاقات ذات حدود شفافة**: `border-border/50` و `bg-card/50` تعطي مظهراً عصرياً
- **تخطيط شبكي متجاوب**: CSS Grid مع نقاط توقف متعددة
- **حالات تفاعلية**: Loading, Error, Empty states مصممة بعناية
- **إشعارات Sonner**: إشعارات أنيقة بدلاً من alerts تقليدية

### المبادئ التفاعلية

1. **الاستجابة الفورية**: كل تفاعل يجب أن يكون له رد فعل مرئي فوري
2. **السلاسة**: استخدام Framer Motion لانتقالات سلسة (spring animations)
3. **التدرج**: الكشف التدريجي عن المعلومات (stagger children)
4. **التركيز**: تمييز العناصر المهمة بالألوان والأحجام
5. **التبسيط**: إخفاء التعقيد خلف واجهات بسيطة

## 4. القرارات المعمارية

### 4.1 لماذا Next.js؟

| السبب | الشرح |
|---|---|
| **App Router** | نظام التوجيه الأحدث مع دعم كامل لـ Server Components و API Routes في مشروع واحد |
| **React Server Components** | تحسين الأداء بتقليل حجم JavaScript المرسل للمتصفح |
| **API Routes مدمجة** | لا حاجة لخادم منفصل — API و Frontend في نفس المشروع |
| **SEO محسّن** | دعم SSR و SSG لتحسين ظهور الموقع في محركات البحث |
| **تحسين الصور** | مكون `next/image` مع تحسين تلقائي للصور |
| **مجتمع ضخم** | توثيق ممتاز ومجتمع نشط وحزم متوافقة |
| **TypeScript أصلي** | دعم مدمج ومحسّن لـ TypeScript |
| **الإصدار 16** | أحدث ميزات React 19 و تحسينات الأداء |

**البدائل المدروسة**:
- ~~Nuxt.js~~: مجتمع أصغر في المنطقة العربية
- ~~Remix~~: أقل نضجاً وأضعف من حيث البنية التحتية
- ~~Vite + React~~: لا يدعم SSR بسهولة

| السبب | الشرح |
|---|---|
| **نوع آمن** | أنواع TypeScript تتولد تلقائياً من المخطط، مما يمنع أخطاء قاعدة البيانات |
| **مخطط declarative** | تعريف المخطط بلغة بسيطة وقابلة للقراءة |
| **ترحيل تلقائي** | `prisma db push` يُحدّث قاعدة البيانات تلقائياً |
| **علاقات معقدة** | دعم سهل للعلاقات بين النماذج (one-to-many, many-to-many) |
| **استعلامات متقدمة** | `include`, `select`, `where`, `orderBy` بواجهة بسيطة |
| **Transactions** | دعم المعاملات الذرية لضمان اتساق البيانات |
| **SQLite للبدء** | لا حاجة لخادم قاعدة بيانات منفصل في البداية |
| **قابلية الترحيل** | سهولة الترقية إلى PostgreSQL أو MySQL عند الحاجة |

### 4.9 نمط التنقل (SPA Pattern)

بدلاً من استخدام Next.js لتنقل الصفحات (file-based routing)، يستخدم المشروع نمط **Single Page Application** حيث:

- `page.tsx` هو نقطة الدخول الوحيدة
- التنقل يتم عبر حالة `currentView` في المكون الرئيسي
- الأحداث المخصصة (`zynex-navigate`, `zynex-order`) للتواصل بين المكونات
- `AnimatePresence` لانتقالات سلسة بين العروض

**المزايا**:
- ⚡ انتقالات فورية بدون تحميل الصفحة
- 🎨 حركات انتقالية سلسة
- 💾 حفظ الحالة عند التنقل
